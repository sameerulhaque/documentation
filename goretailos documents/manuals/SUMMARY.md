# Manuals — one-page summary

⚠️ These files are loaded by the app itself (`/manual`, `/pos-manual`, `/labels-manual`, `/usage`,
`/docs/user-manual`). Do not move, rename or merge them.

| Manual | Covers |
| --- | --- |
| `USER_MANUAL.md` | Every admin form, field and how forms connect: settings, team, catalog, inventory, purchasing, accounting, sales, storefront, AI. |
| `POS_MANUAL.md` | Opening a register, selling, payments, receipts, cash in/out, closing, reprints, returns and refunds. |
| `LABELS_MANUAL.md` | Barcode/label designer: templates, sizes, roll vs sheet, calibration, printing, JSON editing. |
| `usage.md` | Quick tour: user types, first run, sign-in, admin tour, catalog, POS, installing the offline POS app. |

Short version: shop staff start with `usage.md`, cashiers use `POS_MANUAL.md`, managers use
`USER_MANUAL.md`.
