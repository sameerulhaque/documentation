# Design system (single source)

**The live UI standard is the root `SHARED_OS_UI_DESIGN_SYSTEM.md`** (shared with VOXOPlan). The
older specs in this folder were removed (git history).

All rules (tokens, toasts, RTL, modals, tables) live only in that file. Marketing pages use the
"Trexa" theme via `TrexaLayout` (assets in `public/trexa/`).
